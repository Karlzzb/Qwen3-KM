# 千问3医疗分诊AI项目完整说明文档

## 项目说明

本项目在采用了叠加全参数训练模型
首使用**医疗知识库**微调模型，使得模型对医疗知识有自我推导的思维链。
而后进一步引入了 **分诊数据** 进行训练。
使得模型不仅能提供医疗咨询和诊断辅助，还具备了 **分诊与初诊建议** 的能力。
它能够： 
- **问题精炼**：提取用户核心问题给后续流程参考
- **分诊推荐**：根据症状自动推荐对应医院科室  
- **初诊意见**：生成合理的初步诊疗建议

从而更好地模拟真实就医场景下的智能医疗助手。

---

## 核心特性

- 🏥 **智能分诊能力**：自动解析症状，推荐就诊科室  
- 🧠 **初诊意见生成**：结合分诊数据，提供可行的初步诊疗建议  
- 📚 **医疗知识库支持**：保留原有 10 大医疗场景的专业问答能力  
- 🔧 **多种微调方式**：支持全参数微调
- 📊 **端到端训练流程**：数据准备、训练、验证、部署一体化  
- 🎯 **三类提示词优化**：咨询、分诊、初诊

## 技术架构

### 基础模型
- **Qwen3-0.6B**: 项目主要使用的轻量级模型，适合资源受限环境
- **Qwen3-1.7B**: 可选模型，用于对比实验

### 微调技术
1. **全参数微调**: 更新模型所有权重参数
2. **LoRA微调**: 低秩适应，高效微调技术

### 推理风格
- **R1推理风格**: 包含思考过程的推理模式
- **医疗专业提示词**: 针对不同医疗场景优化

## 医疗场景支持

项目支持 **分诊 + 11 个主要科室场景**：  

| 场景ID | 类型 | 科室/领域 | 示例问题 |
|--------|------|-----------|----------|
| 1 | **分诊推荐** | 导诊系统 | "我胸口痛，是去心内科还是呼吸科？" |
| 2 | 初诊意见 | 综合辅助 | "孩子咳嗽发烧，能在家观察吗？" |
| 3 | 内科咨询 | 心内科 / 消化内科等 | "我最近经常胸闷，可能是什么病？" |
| 4 | 外科咨询 | 普外科 / 骨科等 | "摔伤后手臂肿胀疼痛，需要拍片吗？" |
| 5 | 儿科咨询 | 儿科 | "孩子发烧 39 度该怎么办？" |
| 6 | 妇产科咨询 | 妇产科 | "更年期症状如何缓解？" |
| 7 | 老年健康 | 老年医学科 | "老年人如何预防跌倒？" |
| 8 | 营养指导 | 营养科 | "糖尿病患者应该如何选择食物？" |
| 9 | 心理健康 | 心理科 / 精神科 | "最近焦虑失眠，怎么调节？" |
| 10 | 紧急评估 | 急诊科 | "胸痛持续3天，需要立刻去医院吗？" |
| 11 | 疾病预防 | 公共卫生 / 预防医学 | "如何预防心血管疾病？" |
| 12 | 医学教育 | 医学科普 | "什么是高血压？" |

## 使用方式

### 交互式使用
```bash
python medical_assistant.py
```

### 命令行使用
```bash
# 单次问答
python medical_assistant.py -q "我最近头痛，可能是什么原因？" -s diagnosis

# 批量处理
python medical_assistant.py -b sample_questions.json

# 指定模型路径
python medical_assistant.py -c ./output/Qwen3-0.6B/checkpoint-900
```

### 编程接口
```python
from medical_assistant import MedicalAssistant

# 创建助手实例
assistant = MedicalAssistant("./output/Qwen3-0.6B/checkpoint-900")
assistant.load_model()

# 询问问题
response = assistant.ask_question(
    "我最近胃部不适，可能是什么原因？", 
    scenario_type="diagnosis"
)
print(response)
```

## 注意事项

### 医疗免责声明
- 本助手仅提供参考建议，不能替代专业医疗诊断
- 紧急情况请立即就医
- 所有建议仅供参考，具体治疗请咨询专业医生

### 技术限制
- 模型基于训练数据，可能存在知识局限性
- 建议结合最新医学指南使用
- 定期更新模型以保持准确性
